# Qevik — Agent System

## Roles
Potential roles:
- reasoning/planning
- coding
- research
- browser/operator
- media generation
- business/opportunity
- verification/audit

## Provider independence
Support Claude, OpenAI/Codex, local models and specialized media models without hard-coding providers into every caller.

## Evidence
Distinguish evidence-backed claims, inference and unverified assumptions.

## Approval
External or irreversible actions should be explicit approval steps.

## Operator
OpenClaw is the execution layer for terminal, browser, Git, GitHub, cloud consoles and external services. Reasoning model and execution runtime are separate concerns.
