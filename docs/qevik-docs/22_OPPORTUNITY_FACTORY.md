# Opportunity Factory

## Purpose
Turn research into controlled business opportunities.

Pipeline:
Discover → Research → Qualify → Evidence → Proposal → Human approval → Send → Track response

## Evidence
Retain source, evidence, reasoning, target, contact, approval state and proposal fingerprint.

## Current business decisions
Still open:
- niche
- geography
- offer

## First pilot
Use a small manually reviewed set (e.g. 5–10), approve individually, send, inspect results, learn, then increase automation.

Do not immediately enable autonomous high-volume prospecting.
