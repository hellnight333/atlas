# Web Research

Qevik should search the internet, inspect sources, extract evidence, compare options and use results downstream.

Research records should ideally contain:
- query
- URL/title
- evidence/claim
- timestamp where relevant
- confidence/verification

Use search APIs for structured discovery; browser automation for interaction/authenticated workflows/dynamic sites.

OpenClaw is the planned browser/terminal operator. Personal browser sessions should not be exposed by default.
