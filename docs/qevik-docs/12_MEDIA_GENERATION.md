# Media Generation

Capabilities:
- `image.generate`
- `video.generate`
- `speech.generate`
- `music.generate`
- `subtitle.generate`
- `text.generate`

Video is one implementation of generic assembly/timing.

Subtitles should normally derive from known script text. Use generation for translation or unknown source text.

Wan was discussed as a local video workload; exact model/GPU requirements must be tested against the actual version.
