# QEVIK — PROSPECT-SPECIFIC WEBSITE REDESIGN + SALES UX
## FINAL DESIGN / IMPLEMENTATION BRIEF

This task addresses a visible product problem: Qevik can build functional websites, but many prospect demos are too generic and too similar.

The goal is NOT another template. The goal is to prove that Qevik can study a real business's existing website, understand its identity, content, photography, services, story and customer journey, and produce a substantially better website that still feels unmistakably like THAT business.

FIRST REFERENCE CASE
- Prospect: AHS Catering & Events
- Existing website: https://ahscatering.com/
- Current Qevik sample: https://sites.qevik.ai/sample-restaurant/
- Dashboard example: https://app.qevik.ai/#/prospects/6a6f96aa-6ab8-4c34-a5a6-8554c758edd3

The current restaurant sample is NOT acceptable as the AHS concept merely because it is functional.

## 1. CORE RULE

A prospect demo is a "rebuild based on the real business", not "a generic website for that industry".

For each prospect:
1. Inspect the real website and major pages.
2. Extract actual business information.
3. Identify meaningful photography/assets where appropriate for a private sales concept.
4. Understand services and information architecture.
5. Identify what makes the business recognizable.
6. Preserve accurate facts.
7. Improve hierarchy, storytelling, mobile UX and conversion.
8. Build a new visual system specifically for that business.
9. Clearly label it as a Qevik concept/sample, not client work.

Never invent services, staff, awards, testimonials, clients, locations, certifications, prices, statistics, booking integrations or customer relationships.

If an image cannot safely be reused:

## 17. QUALITATIVE DESIGN TEST

For each prospect answer:

1. Would the original business recognize itself?
2. Are real business images/content represented?
3. Does the visual language fit the business?
4. Is the information architecture derived from the business?
5. Is the primary customer journey represented?
6. Is mobile intentionally designed?
7. Does it look like a different brand from other Qevik samples?
8. Does it improve the existing site rather than merely reskin it?
9. Can a prospect understand why Qevik built THIS concept for THEM?
10. Would this be strong enough to show on a sales call?

If any answer is NO, continue.
