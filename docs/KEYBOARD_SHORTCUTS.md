# Keyboard shortcuts

Atlas has **three** global shortcuts. That is the complete list — this page is
generated from reading `useGlobalShortcuts.ts`, not from a plan.

| Shortcut | Does |
|---|---|
| `Cmd + K` / `Ctrl + K` | Open the command palette |
| `Cmd + M` / `Ctrl + M` | Open Mission Control |
| `Esc` | Close the command palette, Mission Control, or the Activity Center |

`Cmd` on macOS, `Ctrl` on Windows and Linux. Both are accepted on every
platform.

## The command palette

`Cmd/Ctrl + K` is the one worth learning. It searches across what Atlas knows
and navigates without the sidebar.

## Standard editing keys

Text fields support the usual system shortcuts — copy, paste, undo, select
all, and word-wise movement — because Atlas uses the platform's native text
handling rather than reimplementing it.

## Why the list is short

A shortcut that does not exist is worse than no shortcut: it teaches a gesture
that fails silently. Rather than publish an aspirational table, this page lists
what is bound today.

More are planned. If a shortcut would save you real time, it is a good
[feature request](https://github.com/hellnight333/atlas/issues/new/choose) —
say which action and how often you do it.
