Studios

A studio is a screen for a kind of work. Below is exactly which ones exist, and which need a model provider that Atlas cannot connect yet.

Public alpha — read before installing

Atlas has no model provider integrations yet. It cannot generate text, images or video today, and no API key will change that. What is complete is everything Atlas does to coordinate work: scheduling, automation, approvals, governance, lineage and recovery — all of which runs with no credentials at all. See exactly what is built.

StudioWhat it is forWorks today
AutomationRules that start work for youFully
Approval CenterWork waiting on a human decisionFully
ClusterMachines, capacity and placementFully
OrganizationTeams, roles and permissionsFully
DiagnosticsHealth, backup, recoveryFully
Activity CenterEverything that has happenedFully
Mission ControlLive view of work in flightFully
ReviewCompare variants, comment, decideFully
AgentAgents, capabilities and teamsPartly
ResearchQuestions, sources, findingsPartly
ImagePrompts, variants, resultsPartly

Partly means the screen, data model and pipeline are real, but the step that would call a model returns a simulated result. Structure works; generation does not.
