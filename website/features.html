Features

Everything on this page is implemented and running today. Anything not built is on the roadmap, never here.

Public alpha — read before installing

Atlas has no model provider integrations yet. It cannot generate text, images or video today, and no API key will change that. What is complete is everything Atlas does to coordinate work: scheduling, automation, approvals, governance, lineage and recovery — all of which runs with no credentials at all. See exactly what is built.

Automation

Rules made of three declarative parts — a trigger, conditions and actions. No code.

  • Schedule, event or manual triggers
  • Dry run shows precisely what a rule would do, without doing it
  • Automation enqueues work through the scheduler and never calls a provider directly
  • Conflict detection between rules that could fight each other

Approvals and governance

Declarative policies that pause execution before a job is created.

GuaranteeWhy
You cannot approve your own requestSeparation of duties, enforced not advised
Only designated approvers decidePolicy names them explicitly
No double-voting toward a quorumOne person is one approval
Decided requests cannot be re-decidedThe record is final

Distributed execution

You never choose a worker. The scheduler places work from what the job requires and what each machine advertises, reserves capacity before creating the job, and returns the slot on every terminal path.

If work is waiting, Atlas names the constraint that failed rather than leaving you guessing.

Knowledge graph

Nodes, edges and lineage across projects, so any output can be traced back to what produced it.

Organizations

Teams, roles, permissions and membership with expiry. Permissions resolve from role data, never a role-name check, so a custom role behaves exactly like a built-in one. Audit is append-only — no kernel path can update or delete a record.

Operations

Diagnostics

Component health and an export that is safe to attach to a bug report — it omits the database URL and every credential.

Backup and restore

Checksummed archives, validation before restore, and restore that is additive rather than destructive.

Crash recovery

Requeues orphaned work, expires dead leases and releases stale reservations. Nothing is deleted.
