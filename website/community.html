Chat

A Discord server is planned but not yet open. It will be announced here and in GitHub Discussions when it exists. Until then, Discussions is the place — and it is searchable, which chat is not.

The planned structure is documented in COMMUNITY.md.

What to expect

  • One maintainer. No support contract, no guaranteed response time. Security reports are acknowledged within five working days
  • Alpha means rough edges. Reporting them bluntly is useful — there is a difference between blunt and contemptuous
  • Some requests will be declined as out of scope. That is a decision, not an opening position — see the roadmap

The most useful things you can do

Say where you got stuck

First-run friction is the hardest thing to see from the inside. Where you gave up is valuable information.

Tell us what you tried to automate

And where Atlas got in the way of it.

Report anything dishonest

A button that does nothing, or a screen claiming a capability that is not there. That is the bug class this project cares most about.
