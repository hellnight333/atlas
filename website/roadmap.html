Roadmap

No dates. This is one person’s project, and a date would be a guess dressed as a commitment.

Shipped — 0.12.0-alpha.2

  • Orchestration: workspaces, projects, runs, steps, jobs
  • Automation engine with dry-run
  • Approvals and governance that pause work before a job exists
  • Worker cluster: placement, reservations, leases, recovery
  • Knowledge graph and lineage
  • Organizations, roles, permissions, append-only audit
  • Diagnostics, backup, restore, crash recovery
  • Desktop installers for Windows, macOS and Linux with PostgreSQL bundled
  • First-run setup and five real example projects

Next — the largest gap

Real model providers. Today Atlas ships two simulation adapters. Until this lands, Atlas coordinates work it cannot yet perform.

  • Cloud adapters: Anthropic, OpenAI, Google — your key, your account
  • Local adapters: Ollama for text, ComfyUI for images
  • Routing: prefer local, fall back to cloud, under cost and quality thresholds
  • Recipes: versioned, benchmarked pipelines in git, so a model is chosen by name rather than improvised

Deliberately never

These are decisions, not gaps. Requests for them will be declined with a link here.

NeverWhy
Auto-updateAn AI system that can replace its own code unasked is a security property nobody agreed to
Telemetry by defaultConsent belongs to a person, not a deployment
Autonomous agents acting without approvalAnything irreversible waits for a human. There is no trusted mode
A marketplaceCuration burden that does not serve the core product
Cloud, SaaS or billingAtlas runs on your machine. That is the point
Mobile appsThe work Atlas does is not phone work
