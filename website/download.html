Download Atlas

Free. Bundles its own PostgreSQL and Python runtime, so there is nothing else to install.

Public alpha — read before installing

Atlas has no model provider integrations yet. It cannot generate text, images or video today, and no API key will change that. What is complete is everything Atlas does to coordinate work: scheduling, automation, approvals, governance, lineage and recovery — all of which runs with no credentials at all. Verify your download

Alpha builds are unsigned, so your operating system cannot vouch for them. Every release publishes SHA256SUMS.txt. Check it before running the file.

shasum -a 256 Atlas_0.12.0-alpha.1_aarch64.dmg        # macOS / Linux
certutil -hashfile Atlas_0.12.0-alpha.1_x64-setup.exe SHA256   # Windows

The warning you will see

macOS: "Atlas cannot be opened because the developer cannot be verified." Right-click the app and choose Open — that specific gesture is the consent macOS accepts. Double-clicking will keep refusing.

Windows: SmartScreen shows "Windows protected your PC". Click More info → Run anyway.

Both happen because signing certificates cost 99–500 USD a year and are not part of the alpha. Checksums are the integrity guarantee instead.
